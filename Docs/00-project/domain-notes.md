# 도메인 메모

## 주요 용어

| 용어 | 의미 |
| --- | --- |
| 입고검사 | 입고된 부품이 기준정보와 일치하는지 확인하는 검사 |
| 기준정보 | 품번, 품명, 분류코드, 분류설명, 구분, 기준 치수, 기준 이미지 |
| 측정부 | 부품 이미지에서 측정해야 하는 위치 또는 선 |
| AI 추론 | 촬영 이미지로 부품 클래스 또는 정상/비정상 여부를 판정하는 처리 |
| OK/Good | 기준정보와 검사 결과가 일치하는 정상 판정 |
| NG | 기준정보와 검사 결과가 불일치하거나 측정값이 기준을 벗어난 판정 |
| 이력 | 검사 결과, 검사 이미지, 이벤트, 판정 근거를 저장한 기록 |
| VLAD Ops | 요구사항 명세서에 언급된 AI/DB/이벤트/측정 알고리즘 연동 영역 |

## 업무상 중요한 점

- 검사자는 빠르게 품번을 입력하거나 스캔하고 검사 결과를 확인해야 한다.
- NG가 발생하면 어떤 부위가 왜 불일치했는지 추적 가능해야 한다.
- 부품별 측정 부위가 다를 수 있으므로 측정 항목은 동적으로 늘어날 수 있어야 한다.
- 기준정보가 잘못 등록되면 검사 품질 전체가 흔들리므로 등록/수정/삭제 권한과 이력 관리가 필요하다.
- 저장공간 정책은 DB뿐 아니라 이미지 파일 보존에도 영향을 준다.
