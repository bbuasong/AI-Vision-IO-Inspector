## SRC-001 요구사항 명세서 분석

요구사항 명세서는 2026-04-15 최초 작성본이며, 시스템의 기본 기능과 화면 골격을 제공한다.

### 시스템 개요

HD현대사이트솔루션 입고 검사 시스템은 입고된 부품의 형상과 등록된 기준 형상이 다를 때
오출고가 발생하지 않도록 검사하는 프로그램이다.

명세서에서 확인된 특징은 다음이다.

- 카메라를 이용한 외관 촬영 후 정상 입고 여부 판별
- 외관상의 두께 및 치수 검출
- 신규 부품 등록
- 등록된 부품 학습

## SRC-002 업무파악 정리파일 분석

업무파악 정리파일은 요구사항 명세서 이후의 개발 관점 분석과 고객 추가 요청을 정리한 자료다.

### 프로젝트 성격

이 시스템은 단순 AI 모델 개발 과제가 아니라 다음 업무 흐름을 하나로 연결하는 Application 개발 과제다.

1. 부품 기준정보 등록
2. 라벨 또는 바코드로 검사 대상 조회
3. 카메라 촬영
4. AI 추론 및 치수 측정
5. OK/NG 판정
6. 검사 결과 저장
7. 이력/통계 조회

### 추가 또는 변경 가능성이 있는 요구

| 항목 | 내용 | 설계 영향 |
| --- | --- | --- |
| 엑셀 일괄등록 | 품번체계 변경 대비 대량 등록 | Import 기능과 검증 로직 필요 |
| 측정부 표시 방식 | 길이/너비/높이/두께 고정이 아니라 이미지 위 선 지정 후 측정부 1, 2, 3 표시 | 측정부 테이블과 동적 UI 필요 |
| 통계정보 | 총 등록 부품수, 검사실적, 검사 품목, OK/NG 수, 평균 검사시간 | 집계 쿼리와 통계 화면 필요 |
| 이력 저장 정책 | 1개월 저장에서 저장공간 기준 삭제로 변경 검토 | 보존 정책/파일 삭제 정책 필요 |
| 바코드/라벨 | 스캐너, QR/바코드, 카메라 기반 라벨 인식 중 최종 방식 확인 필요 | 입력 모듈 분리 필요 |

## 결론

현재 개발 기준은 요구사항 명세서의 기본 기능에 업무파악 정리파일의 추가 요청을 반영해야 한다.
다만 추가 요청 중 일부는 아직 최종 확정이 아니므로 구현 전 확인 질문으로 관리한다.

가장 중요한 설계 방향은 다음이다.

- 측정값은 고정 컬럼보다 측정부 목록 기반으로 관리한다.
- 라벨/바코드 입력 방식은 확정 전까지 입력 어댑터로 분리한다.
- 검사 이력은 DB 데이터와 이미지/로그 파일을 함께 관리한다.
- Application은 UI, 검사 워크플로우, 카메라, AI, DB, 파일 저장을 분리된 모듈로 구성한다.
