# 리뷰 체크리스트

코드 리뷰 또는 자체 점검 시 확인할 항목이다.

## 요구사항

- 변경 내용이 요구사항 ID와 연결되어 있는가?
- 고객 요청과 추정 구현이 구분되어 있는가?
- 미확정 항목을 확정된 동작처럼 구현하지 않았는가?

## 구조

- UI, 검사 흐름, 외부 연동, 저장 로직이 과도하게 한 클래스에 섞이지 않았는가?
- 카메라/AI/DB 연동은 교체 가능한 경계로 분리되어 있는가?
- 측정부가 고정 컬럼에만 묶여 있지 않은가?

## C# 스타일

- 불필요한 람다식이 남발되지 않았는가?
- `delegate` 사용이 꼭 필요한 곳으로 제한되어 있는가?
- .NET Framework 4.5 사용자도 읽기 쉬운 명시적인 구조인가?
- 주요 함수와 업무 흐름에 의도 설명 주석이 있는가?

## 오류 처리

- NG 판정과 시스템 오류가 분리되어 있는가?
- 카메라, AI, DB 실패가 각각 구분되어 로그에 남는가?
- 사용자에게 보여줄 메시지가 개발 로그와 분리되어 있는가?

## 데이터

- 검사 결과와 이미지 경로가 함께 추적되는가?
- 저장 정책 변경에 대비할 수 있는가?
- 엑셀 업로드 실패 행을 확인할 수 있는가?
