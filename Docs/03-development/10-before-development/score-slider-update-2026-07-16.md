# 검사 Score Slider 변경 기록

## 2026-07-16

- 검사 통과 Score와 단일품목 유사값 Score는 소수점 둘째 자리까지 유지한다.
- Slider의 최소값과 최대값은 각각 0점, 100점이다.
- 눈금과 숫자 레이블은 5점 단위로 표시한다.
- 숫자는 Slider의 실제 5점 단위 위치에 맞도록 20등분 Grid 기준으로 배치한다.
- Slider 드래그와 직접 입력은 소수점 값도 허용한다. 눈금은 위치 확인용이며 5점 단위 강제 선택이 아니다.
- 검증: .NET Framework 4.7.2 / x64 Debug 분리 출력 빌드에서 경고 0개, 오류 0개.
