## 우선 답변 필요 항목

1. 실제 카메라 SDK/DLL/드라이버 설치본과 장비 접속 정보
2. AI가 치수를 직접 반환하는지, bbox/mask/keypoint만 반환하는지에 대한 출력 스키마
3. pixel-to-mm 보정 기준물, 절차, 담당 범위
4. 바코드/라벨 입력 장비가 키보드 웨지 스캐너인지 전용 SDK 장비인지
5. OK/NG 이미지 보존 기간과 디스크 한계 정책
