# 인수 기준

요구사항이 실제로 완료됐는지 판단하기 위한 기준이다. 구현 작업을 시작하거나 완료 처리할 때 이 문서를 함께 확인한다.

## 상태 기준

- `완료`: 현재 코드와 문서 기준으로 기능이 구현되어 빌드 검증까지 가능하다.
- `부분완료-검증필요`: 시뮬레이션/파일/기본 흐름은 구현됐지만 실제 장비, AI, 고객 기준 검증이 남아 있다.
- `미구현-내부작업`: 외부 답변 없이 내부 설계/구현을 먼저 진행할 수 있다.
- `미구현-외부정보필요`: 장비, AI, 고객 정책 등 외부 정보가 있어야 완료할 수 있다.
- `보류-범위조정`: 1차 범위 포함 여부를 확정해야 한다.

## 공통 완료 기준

| ID | 기준 | 확인 방법 |
| --- | --- | --- |
| AC-001 | 요구사항 ID가 `requirements.md`와 연결되어 있다. | 요구사항 추적표 확인 |
| AC-002 | 화면, DB, 파일, 연동 영향이 문서에 반영되어 있다. | `02-design/` 문서 확인 |
| AC-003 | 미확정 항목은 구현 확정으로 처리하지 않았다. | `03-development/questions.md` 확인 |
| AC-004 | 정상 흐름과 실패 흐름이 모두 확인되었다. | 테스트/시연 결과 확인 |
| AC-005 | 사용자가 의도를 파악할 수 있도록 주요 함수와 흐름에 주석이 있다. | 코드 리뷰 확인 |
