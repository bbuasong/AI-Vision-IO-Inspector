# 요구사항 명세

## 프로젝트 목표

입고된 부품을 카메라로 촬영하고, 등록된 기준정보와 AI/치수 측정 결과를 비교하여
정상 입고 여부를 판정한다. NG 발생 시 검사 결과, 이미지, 불일치 부위, 이벤트를 저장해
사후 추적이 가능해야 한다.

## 액터

| ID | 액터 | 설명 |
| --- | --- | --- |
| ACT-001 | 운용자 | 시스템 프로그램을 운용하고 기준정보를 등록/관리하는 인원 |
| ACT-002 | 사용자 | 등록된 DB를 이용해 입고 검사를 수행하는 인원 |
