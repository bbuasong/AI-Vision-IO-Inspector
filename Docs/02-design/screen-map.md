## 검사 화면

### 현재 구성

- 좌측 Search DB 단일 검색창과 선택 품목 정보.
- Part Information에 품번, 품명, 분류코드, 분류설명, 구분, 길이/너비/높이/두께 기준정보 표시.
- Event 로그는 좌측 하단에 표시.
- 우측 메인 영역은 6개 카메라 화면이 중심입니다.
- 기준 이미지가 있으면 영상 타일 좌상단 인셋으로 표시합니다.
- 검사 결과는 OK/NG/ERROR 테두리와 판정 텍스트로 표시합니다.
- 버튼은 `기준 이미지 저장`, `검사 시작`, `화면 초기화` 흐름을 기준으로 합니다.

### 상태

| 상태 | 표시 내용 |
| --- | --- |
| Idle | Search DB 입력 또는 품목 선택 대기 |
| 기준정보 조회 완료 | 선택 품목 정보, 기준 이미지, 측정부 기준값 표시 |
| 촬영중 | 6채널 현재 이미지 캡처 |
| 판정중 | AI 추론/측정 처리 |
| OK | 초록 테두리와 정상 판정 표시 |
| NG | 빨간 테두리, 불일치 항목, 측정값/기준값 표시 |
| 오류 | 카메라/AI/DB 오류 메시지와 Event 로그 표시 |

## DB 조회/확인

- 품번, 품명, 분류코드, 분류설명 조건으로 AND 검색합니다.
- 검색어 입력 중 추천 키워드는 검색 중일 때만 표시합니다.
- 선택한 부품의 측정부 상세와 등록 기준 이미지를 확인합니다.
- 기준 이미지 미리보기는 6방향 이미지를 한 번에 확인할 수 있어야 합니다.
- 이 화면은 조회/확인이 목적이므로 DB Update 버튼을 두지 않습니다.

## 부품등록/DB관리

### 단일품목 등록

- 품번, 품명, 분류코드, 분류설명, 구분 입력.
- 기준 이미지 UI를 측정부 UI보다 위에 배치.
- 측정부는 `측정부1`부터 `측정부5`까지 추가/삭제하며 중간 삭제 시 번호를 다시 정렬.
- 각 측정부는 기준값, 허용값, 항목, 위치 표시, X1/Y1/X2/Y2, 단위 `mm`를 관리.
- 위치 표시 버튼은 Thickness 기준 이미지가 있을 때만 활성 흐름을 진행.
- 위치 지정 창에서 시작점/끝점을 클릭해 선과 좌표를 저장하고, 누적 표시와 빨강/주황/노랑/초록/파랑 기본 선 색상 및 RGB 직접 입력을 지원.
- 표시 선은 측정 위치 안내와 AI Crop 기준이며 자동 실측 기능이 아님.
- 기준 이미지는 단독 파일 추가가 아니라 현재 카메라 6개 저장 흐름을 우선합니다.
- 분류코드가 이미 존재하면 기존 분류설명과 다를 때 저장을 차단하고 팝업으로 안내합니다.

### 다중품목 등록

- CSV 불러오기 후 미리보기/검증.
- 컬럼은 품번, 품명, 분류코드, 분류설명, 구분, 측정부1~5의 항목/기준/허용/색상/X1/Y1/X2/Y2, 단위 기준.
- `DB 저장` 버튼으로 현재 기준정보를 교체 저장합니다.
- 다중품목 저장 시 기존 기준 이미지 파일은 자동 삭제하지 않습니다.

## 이력 화면

필요 표시 항목:

- 검사일시 또는 Start/End 기간 검색.
- 품번, 품명, 분류코드, 분류설명, 구분.
- 검사 결과 OK/NG/ERROR.
- 측정값과 기준값은 `150 / 60 / 290 / 10`처럼 간결하게 표시.
- 상세 로그와 이벤트는 필요 시 별도 영역에서 확인.
- CSV 저장은 검색 조건으로 추린 결과를 저장하는 방향입니다.

## 통계 화면

필요 표시 항목 후보:

- 총 등록 부품수.
- 기간별 검사실적.
- 검사 품목 수.
- OK 수.
- NG 수.
- 평균 검사시간.

## 옵션 화면

- `CFG\Config.json` 기준 카메라 정보를 확인합니다.
- `CAMS`에 실제 존재하는 카메라만 표시하고 임의의 6채널 기본 행을 추가하지 않습니다.
- 표시/편집 항목은 카메라 키, `CAM_X`, `CAM_Y`, 형식, `CAM_RTSP_IP`, 상태, 메시지, 확인시각입니다.
- 설정 저장은 기존 JSON 속성을 보존한 채 위 카메라 키 값만 갱신합니다.
- 실제 영상 프레임을 받을 수 있는 상태일 때만 연결됨으로 표시합니다.
- `RuntimeData\Camera\camera-config.json`은 더 이상 사용하지 않습니다.
