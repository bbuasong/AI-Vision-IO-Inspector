# 화면 구성

요구사항 명세서와 포함 이미지를 기준으로 정리한 화면 목록이다.

## 화면 목록

| 화면 ID | 화면명 | 주요 사용자 | 목적 | 상태 |
| --- | --- | --- | --- | --- |
| LGAI001 | 메인화면 | 사용자, 운용자 | 검사 대상 조회, 촬영, 판정 결과 표시 | 요구 |
| LGAI002 | 부품등록 | 운용자 | 신규 부품 기준정보와 기준 이미지 등록 | 요구 |
| LGAI003 | DB 확인 | 운용자 | 등록된 부품 검색 및 선택 | 요구 |
| LGAI004 | DB Update | 운용자 | 기존 기준정보 수정, 엑셀 업로드 | 요구 |
| LHAI004 | 이력화면 | 운용자, 관리자 | 검사 이력 및 NG 결과 조회 | 부분구현-정책검증 |
| LGAI006 | 통계화면 | 운용자, 관리자 | 등록 부품수, 검사실적, OK/NG 수, 평균 검사시간 조회 | 부분구현-고객검증 |

## LGAI001 메인화면

### 확인된 구성

- 좌측 Guide List
- 선택된 부품 정보: Part No, Part Name, 분류코드, 분류설명, 구분, 길이/너비/높이
- 이미지 영역: Top, Front, Back, Left, Right, Thickness
- Thickness 영역에 기준값/측정값 표시
- 등록 부품과 실제 촬영 부품 비교 판별

### 구현 시 필요한 상태

| 상태 | 표시 내용 |
| --- | --- |
| Idle | 입력 또는 선택 대기 |
| 기준정보 조회 완료 | 부품 정보와 기준 이미지 표시 |
| 촬영중 | 카메라 촬영 진행 |
| 판정중 | AI 추론/측정 처리 |
| OK | 정상 판정 표시 |
| NG | 불일치 부위, 측정값, NG 이미지 표시 |
| 오류 | 카메라/AI/DB 오류 메시지 |

## LGAI002 부품등록

### 확인된 입력 항목

- Part No
- Part Name
- 분류코드
- 분류설명
- 구분
- 길이
- 너비
- 높이
- 두께
- 6방향 기준 이미지

### 추가 고려

- 측정부, 측정부2, 측정부3 방식이 최종 요구라면 고정 치수 입력 외에 측정부 등록 UI가 필요하다.
- 기준 이미지 촬영과 파일 업로드 중 어떤 방식을 지원할지 확인해야 한다.
- 등록 전 품번 중복 확인이 필요하다.

## LGAI003 DB 확인

### 확인된 구성

- 검색 입력
- Part No, Part Name, 분류코드, 분류설명, 구분, 길이, 너비, 높이, 두께 테이블
- 선택 행 강조
- Item Input 버튼
- 페이지네이션

## LGAI004 DB Update

### 확인된 구성

- 기존 부품 기준정보 수정
- DB Update 버튼
- 엑셀 업로드 모달
- 지원 형식 이미지 기준: xlsx, xlsm, xlsb

### 남은 검증

- 업로드 파일 컬럼 정의
- 신규/수정/삭제 처리 방식
- 오류 행 리포트 방식
- 업로드 후 롤백 가능 여부

## 이력화면

요구사항 명세서에는 AI 검사 내용을 출력하고 최대 1달 지원한다고 되어 있으나,
업무파악 정리파일에는 저장공간 기준 삭제 방식 변경 검토가 언급되어 있다.

필요 표시 항목 후보:

- 검사일시
- 품번, 품명
- 분류코드, 분류설명, 구분
- 검사 결과 OK/NG
- 측정부별 기준값/측정값
- NG 부위 이미지
- 검사 소요시간
- 이벤트 로그

## 통계화면

업무파악 정리파일의 추가 요청이다.

필요 표시 항목 후보:

- 총 등록 부품수
- 기간별 검사실적
- 검사 품목 수
- OK 수
- NG 수
- 평균 검사시간
