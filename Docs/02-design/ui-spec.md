# UI 명세 초안

요구사항 명세서의 화면 이미지와 현재 분석 내용을 기준으로 한 UI 동작 명세다.

## 공통 UI 원칙

- 현장 작업자가 반복 사용하므로 검사 시작과 결과 확인을 빠르게 할 수 있어야 한다.
- OK/NG, 오류, 대기 상태를 색상과 텍스트로 명확히 구분한다.
- 카메라, AI, DB 오류는 NG 판정과 혼동되지 않게 별도 오류 상태로 표시한다.
- 측정부는 고정 길이/너비/높이/두께만 가정하지 않고 목록 형태로 표시한다.

## 메인 화면

| 영역 | 표시/기능 |
| --- | --- |
| 입력 영역 | 라벨, 바코드, 품번 입력 |
| 기준정보 영역 | Part No, Part Name, 분류코드, 분류설명, 구분 |
| 이미지 영역 | Top, Front, Back, Left, Right, Thickness |
| 측정 영역 | 측정부별 기준값, 측정값, 허용오차, 결과 |
| 결과 영역 | OK/NG, 검사시간, 오류 메시지 |
| 로그 영역 | 검사 이벤트와 연동 오류 |

## 부품 등록 화면

| 영역 | 표시/기능 |
| --- | --- |
| 기본정보 | 품번, 품명, 분류코드, 분류설명, 구분 |
| 기준 이미지 | 6방향 이미지 촬영 또는 파일 등록 |
| 측정부 | 측정부명, 뷰 타입, 좌표, 기준값, 허용오차, 단위 |
| 저장 | 신규 등록, 중복 확인, 필수값 검증 |

## DB 조회/수정 화면

| 영역 | 표시/기능 |
| --- | --- |
| 검색 | 품번, 품명, 분류코드 조건 검색 |
| 목록 | Part No, Part Name, 분류코드, 분류설명, 구분, 측정부 요약 |
| 수정 | 기준정보 변경, 기준 이미지 변경, 측정부 변경 |
| 엑셀 업로드 | 파일 선택, 검증 결과, 반영 결과 표시 |

## 이력 화면

| 영역 | 표시/기능 |
| --- | --- |
| 검색 조건 | 기간, 품번, 판정 결과 |
| 결과 목록 | 검사일, 품번, 품명, OK/NG, 검사시간 |
| 상세 | 촬영 이미지, 측정부 결과, NG 사유, 이벤트 로그 |

## 통계 화면

| 영역 | 표시/기능 |
| --- | --- |
| 요약 | 총 등록 부품수, 검사실적, 검사 품목 수 |
| 판정 | OK 수, NG 수, NG 비율 |
| 성능 | 평균 검사시간 |
| 조건 | 기간, 품번, 분류코드 |
