# Design

프로그램 구조, 데이터 모델, 화면 구성, 외부 연동 구조를 관리합니다.

| 파일 | 내용 |
| --- | --- |
| `architecture.md` | Application 레이어와 주요 모듈 구조 |
| `data-model.md` | DB 테이블 및 파일 저장 구조 초안 |
| `data-spec.md` | 구현 확인용 데이터 필드 명세 |
| `screen-map.md` | 화면 목록과 화면별 역할 |
| `ui-spec.md` | 화면별 표시 항목과 동작 명세 |
| `integration-spec.md` | 카메라, AI, DB, 엑셀, 라벨/바코드 연동 명세 |
| `state-flow.md` | 검사, 등록, 업로드 상태 흐름 |

설계 문서는 확정 요구사항에 맞춰 갱신하고, 미확정 항목은 명확히 표시합니다.
